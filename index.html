DeltaOps · Apps and automation for AEC
02 · ModelChat
Problem

Getting answers out of a BIM model usually needs a specialist and a desktop licence.

What we built

A browser IFC viewer with a chat panel. Claude answers by querying the model index and operating the viewer: isolate, highlight, section, measure.

14
model tools available to Claude6 on the model index · 8 in the viewer
01

Plain-English questions

What is the floor area of Level 3? Show only the columns.

02

Fourteen model tools

Index queries and quantity take-offs, plus actions in the viewer.

03

Runs in the browser

No plug-in or API key. The chat uses a local Claude login.

Built with three.js · web-ifc · Claude Code bakshilabs.github.io/ModelChat-DeltaOps/

06 · Southwark Retrofit Atlas
Problem

Portfolio owners need to know which homes to retrofit first, what it costs, and what a fixed budget covers.

What we built

A costed retrofit package for every home in Southwark, ranked on carbon, need and deliverability, with an adjustable prioritisation model.

149,062
homes costedGLA LBSM 2 · EPC register · ONS
01

Every home mapped

EPC band now and after retrofit, as points or hexagons.

02

Prioritisation

Set a budget and weights, and the programme re-ranks every home.

03

Wards and non-domestic stock

Need by ward, plus 7,045 non-domestic buildings.
